# 引き継ぎメモ（別のAI・別の人が続きを作るために）

最終更新: 2026-11-17。公開先: https://kobayashibiz5884-gif.github.io/manabi-bouken/ （GitHub Pages、main ブランチの直下をそのまま公開。ビルドなし）

## 絶対に守ること
- 子どもの名前・写真・記録をプログラムやこのリポジトリに書かない（公開リポジトリ）。呼び名と記録は端末の localStorage（キー `manabi-bouken-v1`）だけにある。
- 既存作品（ロブロックス、呪術廻戦、ゼルダ等）のキャラクター・名前・音楽は使わない。物語は完全オリジナル。
- 使う親はプログラミング経験なし。説明は専門用語なしで、操作は1つずつ。
- 妹は間違えても責めない（×印・ブザーなし）。形の似たひらがなは、慣れるまで同じ問題に並べない。

## 全体の作り（外部の部品なし。素の HTML/CSS/JavaScript）
| ファイル | 役割 |
|---|---|
| `index.html` | 入口。読み込み順が大事（srs → store → audio → judge → speech → data → logic → app → 各画面）。直したら `?v=` の数字を上げる |
| `js/srs.js` | 復習の仕組み。箱0〜7、間隔 1,2,4,7,14,30,60日。間違えると箱−2で当日再出題、翌日も確認 |
| `js/store.js` | 保存、1日の時間、1日1話の制限（`canPlay`）、控えの書き出し |
| `js/audio.js` | 読み上げ（speechSynthesis）と効果音（WebAudio）。`{漢字|よみ}` のふりがな記法 |
| `js/judge.js` | 声の答えの判定（日本語・英語・「パス」「もういちど」） |
| `js/speech.js` | 聞き取り（webkitSpeechRecognition）の包み。失敗前提 |
| `data/kana.js` | ひらがな/カタカナ、例のことば、似た字の組、ことば問題 |
| `data/kanji.js` | 1年生80字。表示のことば・読み・絵・同音の書き方 |
| `data/english.js` | 英単語 約150語、レベル1〜5 |
| `data/story.js` | 兄の物語25日分＋おまけ3種のくり返し |
| `js/sister-logic.js` / `js/sister.js` | 妹: 出題の組み立て / 画面（お菓子屋さん） |
| `js/brother-logic.js` / `js/brother.js` | 兄: 出題・英語レベル自動調整 / 画面（冒険、声） |
| `js/parent.js` | 親: 初期設定、暗証番号、記録、設定、声のテスト |
| `tests/` | `node tests/test-sister.js`、`node tests/test-brother.js`（データ・判定・復習の点検。直したら必ず実行）。`e2e-*.js` は Playwright での通しテスト（`python3 -m http.server 8765` で配信して実行） |

## 点検したこと / していないこと
- 済: 自動点検（上の2本）すべて合格。テスト用ブラウザ（WebKit、iPhone 13 の画面サイズ）で、妹14日分・兄11日分を通しで遊ばせてエラーなし。兄は「にせの聞き取り」で声の流れも通した。
- **未確認（実機でしか分からない）**: iPhone 実機での読み上げの声、子どもの声の聞き取り、ホーム画面アイコンからの聞き取り、聞き取り中の音量、画面が暗くならないか。`docs/CHECKLIST.md` の結果を見て直すこと。
- 学校で習った漢字の初期値（並びの先頭35字）は推定。教科書の実際の順ではない。親の画面で直せる。

## 未完成・気になる点
1. 妹: 読み上げが「は」「へ」を正しく読むか未確認（カタカナで読ませて回避しているつもり）。だめなら「親の声を録音して使う」機能を足す（MediaRecorder＋IndexedDB）。
2. 妹: 材料が飛ぶアニメ（`.fly`）が連続正解で重なって見える可能性。兄ホームの題名が左上の🏠ボタンに少し近い。
3. 兄: 聞き取りと読み上げを交互に使うと iPhone で音量が下がる可能性。物語の読み上げは、かなが多く読みまちがいがありうる（`data/story.js` のふりがな記法で漢字を増やすと改善）。
4. 兄: 曜日の問題はヒントの絵が全部📅で区別がつかない。
5. 26日目以降の物語は3種類のくり返し。`DAYS` に書き足せば続く（5日ごとにボス、最後の行は「つづきは、また あした。」）。
6. 記録の控えは文字のコピー＆貼り付け方式。ファイル保存にしたほうが楽。
7. オフライン用の `sw.js` は未検証。
