# 子どもに試してもらうときのチェックリスト

## 始める前（親だけで）
1. iPhone の Safari で https://kobayashibiz5884-gif.github.io/manabi-bouken/ を開く
2. 画面下の「共有」ボタン（四角から矢印）→「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから開き、「はじめの設定」を入れる（暗証番号、妹の名前をひらがなで）
4. 本体横の消音スイッチを切り、音量を上げる
5. 「⚙️ おとな」→「⚙️ 設定」で、学校で習った漢字を実際に合わせて直す
6. 「🎤 声のテスト」で「読み上げの声のテスト」3つを押し、声が出るか、「は」「へ」が正しく聞こえるか確かめる

試し終わったら、同じ日にもう一度遊ばせたいときは「設定」→「今日もう1回 遊べるようにする」。

## 妹（5歳）— 見ること
- [ ] 声の説明だけで、何をすればいいか分かったか（分からなかった場面をメモ）
- [ ] 読み上げは聞き取りやすいか。おかしな読み方をした文字・ことば（例:「は」が「わ」）
- [ ] ボタンは押しやすいか。押しまちがい、反応しない場面
- [ ] 間違えたとき、いやな顔をしなかったか。もう一度選べたか
- [ ] 最初の5文字は多すぎないか（終わったあと、親の画面の「れんしゅう中」「にがて」を見る）
- [ ] かざりつけを楽しんだか。終わったあと「あしたも やる」と言ったか
- [ ] かかった時間（親の画面の「今日」）。10分より長い／短い

## 兄（7歳）— 見ること
- [ ] 最初の「ひらけ」で声が通ったか。ホーム画面のアイコンからでだめなら、Safari から開いて同じことを試す
- [ ] 声で答えたとき、正しく言えたのに不正解になった問題（**漢字と、画面に小さく出る「聞こえたことば」をメモ**。これが一番役に立ちます）
- [ ] 間違って言ったのに正解になった問題
- [ ] 英語: 言えたのに通らなかった単語と「聞こえたことば」
- [ ] 英語が簡単すぎ／難しすぎないか（親の画面で今のレベルが見られる。設定で変えられる）
- [ ] 物語の読み上げは聞き取れたか。読みまちがいが気になった文
- [ ] 読み上げの声が途中から小さくならなかったか
- [ ] 遊んでいる間に画面が暗くならなかったか
- [ ] スマホに触らずに最後まで進めたか。触った場面
- [ ] 「つづきは また あした」で、続きを気にしたか

## 数日続けたあと
- [ ] 2日目以降、前の日の文字・漢字がまた出てきたか
- [ ] 親の画面の「おぼえた」「にがて」が、実感と合っているか
- [ ] 記録が消えていないか（親の画面「設定」→「控えをコピー」で控えを取る）
